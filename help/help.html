はじめに

ClipSave for Windows をご利用いただき、ありがとうございます。

ClipSave は、ホットキー 1 つで画面をキャプチャし、自動的に連番ファイル名で保存する軽量ユーティリティです。Windows 10/11 の高 DPI 環境にも完全対応しています。

🖥️ 3つのキャプチャモード

フルスクリーン、アクティブウィンドウ、クライアント領域から選択

💾 3つの保存形式

JPEG、BMP、PNG に対応

🎯 DPI 完全対応

125%/150% 表示でもピクセル完璧

🖱️ カーソル描画

カーソルを含めたキャプチャが可能

📋 クリップボード連携

クリップボードの画像・テキストを自動保存

📝 メモ登録機能

タスクトレイ左クリックで簡易メモ入力

使い方

起動と終了

  • 起動: ClipSave.exe をダブルクリック。タスクトレイにアイコンが表示されます
  • 終了: タスクトレイアイコンを右クリック → 「終了」

画面キャプチャの基本

画面をキャプチャするには、Ctrl + Shift + C キーを押します。

📝 Note: 左手で操作しやすい Ctrl+Shift+C を採用（"C" for ClipSave）。従来の PrintScreen キーは Windows 10/11 でシステムが予約済み。

キャプチャされた画像は、設定した保存先フォルダに自動的に保存されます（デフォルト: .\clipfiles\）。

キャプチャモード

モード 説明 用途
フルスクリーン 画面全体をキャプチャ（マルチモニタ対応） デスクトップ全体のスナップショット
アクティブウィンドウ フォアグラウンドウィンドウのみキャプチャ 特定のアプリケーション画面
クライアント領域 ウィンドウのタイトルバーやフレームを除いたキャプチャ アプリケーションの内容部分のみ
モード切替: タスクトレイ右クリック → フルスクリーン/アクティブウィンドウ/クライアント領域

タスクトレイアイコン

  • 左クリック: メモ入力ダイアログを表示（簡易メモ機能）
  • 右クリック: 設定メニューを表示

メモ機能

タスクトレイアイコンを左クリックすると、「メモを登録」ダイアログが表示されます。登録ボタンを押すと、設定したメモファイル（デフォルト: ClipSaveMemo.txt）に日付時刻付きで追記されます。

  • 相対パスの場合は、画像保存フォルダ内に作成されます
  • 絶対パスを指定すれば、その場所に保存されます

設定

設定ダイアログ: タスクトレイ右クリック → 設定

保存設定

  • 保存先ディレクトリ: キャプチャ画像の保存先フォルダ
  • 保存形式: JPEG / BMP / PNG から選択
  • JPEG 画質: 0-100（値が大きいほど高画質、ファイルサイズ大）
  • ファイル名形式:
    • yyyymmdd.nnn.ext - 日付ベースの連番
    • Prefix + yyyymmdd.nnn.ext - 接頭辞付き
    • ユーザー定義 - カスタムパターン

キャプチャ設定

  • キャプチャ範囲: フルスクリーン / アクティブウィンドウ / クライアント領域
  • 24bit カラーモード: BMP 保存時に 24bit カラーに変換
  • カーソルを含める: カーソルを画像に含めてキャプチャ
  • 音を鳴らす: キャプチャ時に WAV ファイルを再生

クリップボード連携

クリップボード連携を有効にすると、ClipSave はクリップボードを監視し、画像やテキストがコピーされると自動的にファイルに保存します。

  • 画像は必ず保存: クリップボードの画像を自動保存（常に有効）
  • テキストを保存: クリップボードのテキストを自動保存（設定画面でON/OFF可能）
  • テキストは追記する: 既存ファイルに追記（新規作成しない）
💡 Tip: クリップボード連携モードでは、タスクトレイアイコンの色が紫色に変わります。

メモ設定

  • メモ保存ファイル名: タスクトレイ左クリックで入力したメモの保存先ファイル名

Tips & Tricks

高 DPI 環境での使用

ClipSave は Windows 10/11 の 125%/150% DPI スケーリング環境で完全動作するよう設計されています。物理解像度で正確にキャプチャされます。

マルチモニタ環境

フルスクリーンモードでは、すべてのモニタを含む仮想スクリーン全体をキャプチャします。特定のモニタのみキャプチャしたい場合は、アクティブウィンドウモードを使用してください。

ファイル名のカスタマイズ

ユーザー定義パターンを使用すると、時刻やミリ秒を含む柔軟なファイル名を設定できます。

右クリックメニューから素早く設定変更

設定ダイアログを開かなくても、右クリックメニューから以下を直接切り替えられます：

  • キャプチャモード（フルスクリーン/アクティブウィンドウ/クライアント領域）
  • 保存形式（JPEG/BMP/PNG）
  • カーソルを含める ON/OFF
  • クリップボード連携 ON/OFF

保存フォルダを素早く開く

タスクトレイ右クリック → 保存フォルダを開く

トラブルシューティング

ホットキーが動作しない

⚠️ 確認事項:
  • 他のアプリケーションが Ctrl+Shift+C を使用していないか確認
  • ClipSave が起動しているか確認（タスクトレイにアイコンがあるか）
  • 管理者権限で起動しているアプリでは動作しない場合があります

キャプチャした画像が真っ黒

DirectX フルスクリーンアプリケーションや、保護されたコンテンツではキャプチャできない場合があります。以下を試してください：

  • アプリケーションをウィンドウモードに変更
  • 別のキャプチャモード（アクティブウィンドウ → フルスクリーン）を試す

メモが保存されない

相対パス（ファイル名のみ）を指定した場合、画像保存フォルダ内に作成されます。絶対パスを指定している場合は、ディレクトリが存在するか確認してください。

設定が保存されない

ClipSave.ini ファイルが読み取り専用になっていないか確認してください。ファイルは実行ファイルと同じフォルダに作成されます。

カーソルの位置がずれる

Windows 10/11 の DPI スケーリング環境では自動的に補正されますが、特殊な DPI 設定では正常動作しない場合があります。その場合は「カーソルを含める」をオフにしてください。
